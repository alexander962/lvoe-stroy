# Focus Board mock API

Локальный HTTP API для учебных сценариев RTK Query. Данные хранятся в
памяти и возвращаются к исходному состоянию после перезапуска сервера.

## Запуск

```bash
npm run api
```

API доступен по адресу `http://localhost:4000`. По умолчанию каждый ответ
задерживается на 600 мс. Задержку можно изменить:

```bash
MOCK_API_DELAY=1000 npm run api
```

## Endpoints

- `GET /tasks` — получить все задачи.
- `GET /tasks/:id` — получить задачу по идентификатору.
- `POST /tasks` — создать задачу.
- `POST /__test/reset` — восстановить исходные задачи.
- `POST /__test/fail-next` — вернуть ошибку при следующем создании задачи.

Тело запроса для создания задачи:

```json
{
  "title": "Изучить RTK Query",
  "description": "Подключить загрузку списка через HTTP API.",
  "status": "planned",
  "priority": "high"
}
```

Сервер самостоятельно добавляет `id` и `createdAt`.

## Управление состоянием

Вернуть исходные пять задач:

```bash
npm run api:reset
```

Сделать следующий `POST /tasks` ошибочным:

```bash
npm run api:fail-next
```

После ответа со статусом 500 одноразовая ошибка автоматически выключается.
